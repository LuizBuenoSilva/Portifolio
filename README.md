# Luiz Henrique — Dev World

Portfólio interativo em formato de mundo explorável.

Em vez de uma lista tradicional de projetos, o visitante controla um personagem e caminha por uma pequena cidade. Cada construção representa um repositório e pode ser visitada para ver uma descrição, tecnologias usadas e um atalho para o GitHub.

## Controles

- **WASD** ou **setas**: movimentação
- **E**: interagir com o projeto mais próximo
- **ESC**: fechar o projeto aberto
- No celular, use o direcional exibido na tela

## Projetos representados na cidade

A primeira versão destaca alguns repositórios públicos, incluindo:

- Organizei
- Commander Points
- EventTec
- FootBall SaaS
- IA Animal
- DIO Bank
- Login Page
- Minecraft
- Cardápio
- HLTV Bot

## Stack

- Angular 17
- TypeScript
- SCSS
- Angular SSR

A V1 não depende de engine de jogos externa. A movimentação, câmera, mapa e interações foram implementadas diretamente no Angular para manter o bundle leve.

## Rodando localmente

```bash
npm install
npm start
```

Abra `http://localhost:4200`.

## Build

```bash
npm run build
```
